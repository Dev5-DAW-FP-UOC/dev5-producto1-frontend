# Producto 1 – FrontEnd (Dev5)

## Descripción
Este repositorio contiene el desarrollo del **FrontEnd** de la aplicación de voluntariado.  
Se trabajará con **HTML5, CSS, JavaScript** y el framework **Bootstrap** para crear una interfaz responsive y usable.

## Objetivos
- Aplicar las tecnologías básicas de desarrollo de interfaces (HTML5, CSS3).
- Aprender y aplicar **JavaScript** para la interacción con el usuario.
- Introducir el uso de **Bootstrap** para mejorar la usabilidad y diseño.
- Empezar a usar **Git** para el control de versiones.
